# Dress Rental Web

Киім (көйлек) жалға беру веб-сайты. Қолданушы каталогтан көйлек таңдап,
сипаттамасы мен бағасын көріп, жалға алуға өтінім қалдыра алады.

## Технологиялар
- React
- Java / Spring Boot (жоспарда)

## Іске қосу

npm run dev
